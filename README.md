
# Task 3: Task Automation with Python Scripts

## Objective
Automate the process of moving all JPG files from one folder to another.

## Technologies Used
- Python
- os module
- shutil module

## How to Run

1. Place JPG files inside the `source_images` folder.
2. Run:

```bash
python move_jpg_files.py
```

3. All JPG files will be moved to the `jpg_files` folder.

## Output

Example:

Moved: photo1.jpg
Moved: photo2.jpg
All JPG files have been moved successfully.
